# Kayotic Tutoring Website

A professional, responsive website for your tutoring business that showcases your services and allows potential clients to schedule sessions and make inquiries.

## Features

- **Modern, Professional Design** - Clean, trustworthy appearance that builds confidence
- **Responsive Layout** - Works perfectly on all devices (desktop, tablet, mobile)
- **Service Showcase** - Highlight all subjects you tutor (Math, Science, English, etc.)
- **Contact Form** - Easy way for clients to reach out and schedule sessions
- **Mobile-First Navigation** - Hamburger menu for mobile devices
- **Smooth Animations** - Professional feel with subtle animations and transitions
- **SEO Optimized** - Proper meta tags and semantic HTML structure

## Quick Start

1. **Open the website locally:**
   - Double-click `index.html` to open in your browser
   - Or drag `index.html` into your browser window

2. **Test all features:**
   - Navigate through all sections
   - Try the contact form
   - Test mobile responsiveness by resizing your browser
   - Check that all links work properly

## Customization Guide

### Update Business Information

**Company Name & Branding:**
- Edit the title in `index.html` (line 6)
- Change "Kayotic Tutoring" throughout the file to your business name
- Update the logo text in the navigation (line 32)

**Contact Information:**
- Update email: `info@kayotictutoring.com` → your email
- Update phone: `(555) 123-4567` → your phone number
- Update business hours if different

**Services:**
- Modify the 6 service cards in the Services section (lines 67-108)
- Add/remove subjects based on what you actually tutor
- Update descriptions to match your expertise

### Update Content

**Hero Section:**
- Change the main headline: "Unlock Your Academic Potential"
- Update the description paragraph
- Modify call-to-action buttons

**About Section:**
- Customize the benefits list to match your unique selling points
- Add your qualifications, experience, or special approach

**Pricing (Optional):**
- Add a pricing section if you want to display rates
- Include package deals or hourly rates

### Styling & Colors

**Primary Colors:**
- Main blue: `#2563eb` (used for links, icons, accents)
- Accent orange: `#f59e0b` (used for primary buttons)

**To change colors:**

## Deployment Options

### Option 1: Free Hosting (Recommended for starting out)

**GitHub Pages (Free):**
1. Create a GitHub account
2. Create a new repository named `yourname.github.io`
3. Upload these files to the repository
4. Your site will be live at `https://yourname.github.io`

**Netlify (Free):**
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop your website folder
3. Get a free URL like `https://random-name.netlify.app`
4. Option to add custom domain later

### Option 2: Paid Hosting (More professional)

**Domain + Hosting:**
1. Buy a domain (e.g., `yourtutoring.com`) from Namecheap, GoDaddy, etc.
2. Get hosting from providers like:
   - Bluehost ($3-7/month)
   - HostGator ($3-6/month)
   - SiteGround ($4-7/month)

### Option 3: Website Builders (Easiest)

**Wix, Squarespace, or WordPress:**
- Copy the design and content from this HTML site
- Use their drag-and-drop editors
- More features but monthly costs

## Technical Support

### Common Issues

**Website not loading:**
- Check all files are in the same folder
- Ensure file names match exactly (case-sensitive)
- Try opening in different browsers

**Form not working:**
- The form currently shows a success message (demo mode)
- To make it functional, you'll need backend integration
- Consider using Formspree, Netlify Forms, or similar services

**Mobile issues:**
- Test on actual mobile devices
- Check that all CSS and JavaScript files are loading
- Clear browser cache

### Adding Real Form Functionality

**Option 1: Formspree (Easiest)**
1. Go to [formspree.io](https://formspree.io)
2. Create account and get form endpoint
3. Replace the form action in `index.html`
4. Form submissions go to your email

**Option 2: Netlify Forms**
1. Deploy to Netlify
2. Add `netlify` attribute to form
3. Submissions appear in your Netlify dashboard
